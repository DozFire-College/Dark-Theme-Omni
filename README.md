# Тёмный Omni
Тёмная тема для журнала преподавателя omni.top-academy.ru.
Настройки те же, что у «Тёмного журнала» для студентов: три палитры (Графит, Полночь, AMOLED),
умная подстройка и быстрое включение/выключение по Alt+Shift+D.


# Как установить
1. Скачайте архив исходного кода.
2. Распакуйте его в любую папку. Не удаляйте папку.
3. Включить режим разработчика в браузере (Работает в Egde, Opera, Yandex и в Chrome)
4. Добавить папку, в которую распаковали архив
